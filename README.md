# ⚡ yt (macOS Edition)

[![Platform](https://img.shields.io/badge/Platform-macOS%20(Apple%20Silicon%20%2F%20Intel)-000000?style=for-the-badge&logo=apple&logoColor=white)](https://apple.com)
[![Bash](https://img.shields.io/badge/Shell-Bash%20%2F%20Zsh-4EAA25?style=for-the-badge&logo=gnu-bash&logoColor=white)](https://www.gnu.org/software/bash/)
[![Engine](https://img.shields.io/badge/Engine-yt--dlp%20%2B%20ffmpeg-FF0000?style=for-the-badge&logo=youtube&logoColor=white)](https://github.com/yt-dlp/yt-dlp)

Интерактивный, быстрый и стильный консольный медиа-загрузчик с красивым TUI-меню, анимациями и пресетами качества.  
Проект спроектирован **преимущественно для macOS** с глубокой интеграцией в систему (буфер обмена, Finder, системные уведомления и звуки), но также совместим с Linux.

Поддерживает загрузку с **YouTube, VK Видео, Rutube, TikTok, Twitter/X, Instagram, Vimeo, SoundCloud** и более чем 1000 других медиа-платформ.

---

## 🛠️ Зависимости (Dependencies)

Для полноценной работы загрузчика используются 3 ключевые утилиты:

| Утилита | Зачем нужна в проекте | Как устанавливается |
| :--- | :--- | :--- |
| **`yt-dlp`** | Основной движок загрузки. Извлекает видео/аудио потоки с YouTube и сотен сайтов на максимальной скорости. | `brew install yt-dlp` |
| **`ffmpeg`** | Мультимедийный комбайн. Склеивает видео сверхвысокой чёткости (1080p, 2K, 4K) со звуком, конвертирует в MP3/M4A/FLAC, вшивает обложки и теги. | `brew install ffmpeg` |
| **`fzf`** | Интерактивное нечеткое меню в терминале. Обеспечивает красивую навигацию со стрелочками и поиском. *(Если не установлен — скрипт использует встроенное консольное меню)*. | `brew install fzf` |

> 💡 **Вам не нужно устанавливать их вручную!** В проект встроен скрипт `install.sh`, который сам проверит и настроит всё необходимое на вашем Mac в 1 клик.

## 🍎 Особенности для macOS

- 📋 **Интеграция с буфером обмена (`pbpaste`)**: просто скопируйте ссылку на видео в Safari/Chrome (`Cmd + C`) и запустите скрипт — он сразу предложит использовать её без необходимости вставки вручную.
- 🔔 **Системные уведомления macOS**: после окончания загрузки Mac воспроизводит приятный звук (*Glass*) и показывает баннер уведомления с именем сохранённого файла.
- ⚡ **Многопоточное ускорение (`-N 4`)**: загрузка сегментов видео в 4 параллельных потока ускоряет скачивание в 3–5 раз.
- 🏷️ **Метаданные, главы и обложки**: обложки высокого разрешения и оглавления глав (chapters) автоматически вшиваются в файлы MP4/MKV/MP3 и корректно отображаются в Finder, QuickTime и Музыке (Apple Music).
- 📂 **Управление через Finder**: прямо из меню после загрузки можно открыть папку с файлом в Finder (`open`) или запустить просмотр в дефолтном плеере (QuickTime / IINA / VLC).
- 🍏 **Нативная поддержка Apple Silicon & Intel**: скрипт автоматически определяет архитектуру (`arm64` M1/M2/M3/M4 или `x86_64` Intel) и пути Homebrew (`/opt/homebrew` и `/usr/local`).

## 🚀 Быстрый старт (Инструкция)

### Шаг 1. Клонирование репозитория
Откройте программу **Терминал** и выполните:
```bash
git clone https://github.com/gitmarkedit/yt.git
cd yt
```

### Шаг 2. Автоматическая установка зависимостей
Запустите скрипт автонастройки:
```bash
bash install.sh
```
*Скрипт сам проверит наличие Homebrew, установит `yt-dlp`, `ffmpeg`, `fzf` и настроит короткую системную команду `yt`.*

### Шаг 3. Запуск
Теперь вы можете запускать программу из **любой папки терминала** просто одной командой:
```bash
yt
```
Или передав ссылку напрямую:
```bash
yt "https://www.youtube.com/watch?v=..."
```

*(Также всегда доступен локальный запуск через `bash start.sh` внутри папки).*

## 🎛️ Меню и режимы работы

После запуска скрипт показывает анимированный спиннер, карточку с информацией о ролике (автор, название, длительность, просмотры) и интерактивное меню:

```text
╭─ 📺 Информация о медиа ───────────────────────────────────────╮
│ Название:  Sample Video Title
│ Автор:     Channel Name
│ Время:     14:20
│ Просмотры: 1,234,567
╰───────────────────────────────────────────────────────────────╯
```

### Доступные действия:
1. 🚀 **Максимальное качество (Best Video + Audio)** — в 1 клик скачивает наилучшее качество (4K / 1080p 60fps) и склеивает в MP4.
2. 🎵 **Сразу MP3 (320 kbps)** — мгновенно извлекает звук с обложкой и тегами без лишних вопросов.
3. 🪶 **Минимальный вес (Эконом)** — скачивание с минимальным размером файла (удобно для подкастов и лекций).
4. 🎯 **Выбрать точное разрешение** — ручной выбор: 2160p (4K), 1440p (2K), 1080p, 720p, 480p, 360p + контейнер (MP4, MKV, WebM).
5. 🎧 **Другие аудиоформаты** — M4A/AAC (Apple нативный без пересжатия), FLAC (студийный Lossless), WAV, OPUS, Direct Stream.
6. ✂️ **Скачать отрезок по времени (Time-slice)** — ввод интервала (например: `01:15-02:45`), чтобы скачать только нужную часть без всего видео.
7. 📜 **Загрузить плейлист** — загрузка всего плейлиста или диапазона номеров (например: `1-5`).
8. 📋 **Список форматов (`yt-dlp -F`)** — просмотр всех технических кодеков и потоков и ввод точного ID.
9. 💬 **Субтитры** — загрузка русских, английских или автогенерированных субтитров (.srt / .vtt).
10. 🖼️ **Скачать только обложку** — сохранение постера ролика в максимальном HD-качестве (.jpg).
11. ⚙️ **Настройки** — смена папки загрузок (по умолчанию `~/Downloads/Media`), переключение обложек, метаданных и числа потоков скачивания.

## ⚙️ Конфигурация

Все пользовательские настройки сохраняются в конфигурационном файле:
`~/.config/yt-downloader/config.env`

Вы можете изменить папку загрузки по умолчанию, количество потоков или отключить вшивание обложек через меню настроек прямо в скрипте.
